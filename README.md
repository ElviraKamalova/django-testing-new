# Проектная работа: тесты для YaNews

В этой работе нужно написать тесты для Django-проекта YaNews с помощью
pytest и pytest-django. Код приложения уже готов: изменять его не требуется.

Редактируйте только файлы в директории
`ya_news/news/pytest_tests/`:

- `conftest.py` — общие фикстуры;
- `test_routes.py` — маршруты и права доступа;
- `test_content.py` — содержимое страниц;
- `test_logic.py` — создание, изменение и удаление комментариев.

## Что проверить

В `test_routes.py` проверьте:

- доступность главной страницы, отдельной новости, входа и регистрации;
- доступ автора к изменению и удалению своего комментария;
- ответ 404 для пользователя, который обращается к чужому комментарию;
- перенаправление анонимного пользователя на страницу входа;
- выход авторизованного пользователя через POST-запрос.

В `test_content.py` проверьте:

- ограничение числа новостей на главной странице;
- сортировку новостей от новых к старым;
- сортировку комментариев от старых к новым;
- наличие формы комментария только у авторизованного пользователя.

В `test_logic.py` проверьте:

- запрет на создание комментария для анонимного пользователя;
- создание комментария авторизованным пользователем;
- отклонение комментария со стоп-словом, например «редиска», с сообщением
  «Не ругайтесь!»;
- изменение и удаление собственного комментария;
- запрет на изменение и удаление чужого комментария.

Выносите общие данные в фикстуры, соблюдайте AAA и применяйте
параметризацию там, где отличается только набор входных данных.

## Подготовка и проверка

Для работы нужен Python 3.14.

```bash
python -m venv venv
python -m pip install -r requirements.txt
python ya_news/manage.py migrate
python ya_news/manage.py check
pytest
flake8
python structure_test.py
```

Перед отправкой убедитесь, что все четыре команды проверки завершаются без
ошибок и в архив не попали база данных, кеши или виртуальное окружение.
